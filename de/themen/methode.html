Methode

Schrittwas geschieht
VorverarbeitungDas Fachkonzept wird in Kapitel, Absätze und Tabellen zerlegt; jede Anforderung hat eine Kennung.
ExtraktionEin Sprachmodell (KI) liest Kapitel für Kapitel Abläufe, Regeln und die Fachobjekte heraus; Fachexperten prüfen und übernehmen.
Code und BPMN lesenKlassen, Methoden, Nachrichten und Prozesselemente werden ohne Sprachmodell aus dem Repository gelesen.
AbgleichFeste Prüfregeln vergleichen Fachkonzept, Prozess und Code und melden Lücken – jede mit Beleg: der Stelle im Dokument, dem Element im Modell, der Zeile im Code.
KurationFachexperten bestätigen Lücken oder markieren Fehlalarme; daraus werden die Regeln geschärft.

Die öffentliche Demo zeigt das Ergebnis zum Lesen. Geprüft und entschieden wird im Curator, der Arbeitsoberfläche für Fachexperten, auf dem eigenen Rechner. Ein Beispiel von Anfang bis Ende: So findet Kanonik eine Lücke.
