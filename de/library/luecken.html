K03Nachricht BookAddedToCatalogue fehlt im Code
Laut Kapitel 7 sendet Katalog „Buch aufgenommen“ (BookAddedToCatalogue); im Code verschickt sie kein Dienst. Im Code kommt sie gar nicht vor – keine Klasse, kein Name.
Wo im Code: Absender laut Fachkonzept: Katalog – im Code der Dienst „catalogue“. Naheliegende Stellen (senden dort schon Nachrichten bzw. nennen die Nachricht): Catalogue.addBook (sendet bisher nichts – Gegenstück zu addBookInstance, das BookInstanceAddedToCatalogue sendet); Catalogue.addBookInstance (sendet BookInstanceAddedToCatalogue über saveAndPublishEvent); Catalogue.saveAndPublishEvent (sendet BookInstanceAddedToCatalogue)		fehltCodeA-5.1-1bestätigt
K04Nachricht BookReturned wird nie gesendet
Laut Kapitel 7 sendet Ausleihe „Exemplar zurückgegeben“ (BookReturned); im Code verschickt sie kein Dienst. Die Nachricht ist im Code bekannt (src/main/java/io/pillopl/library/lending/patron/model/PatronEvent.java: Klasse PatronEvent.BookReturned), wird aber nirgends verschickt.
Wo im Code: Absender laut Fachkonzept: Ausleihe – im Code der Dienst „lending“. Naheliegende Stellen (senden dort schon Nachrichten bzw. nennen die Nachricht): CheckingOutBookOnHold.checkOut (sendet BookCheckedOut über checkOut, sendet BookCheckingOutFailed über checkOut); CancelingHold.cancelHold (sendet BookHoldCanceled über cancelHold, sendet BookHoldCancelingFailed über cancelHold); HandleDuplicateHold.handle (sendet BookHoldCanceled über cancelHold, sendet BookHoldCancelingFailed über cancelHold)
