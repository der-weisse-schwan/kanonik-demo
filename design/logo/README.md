# Logo von Kanonik

Bildzeichen: ein „K“ aus Knoten eines Graphen – links die Spezifikation (Säule aus drei Knoten), rechts die Umsetzung;
der offene grüne Knoten steht für die Lücke, die Kanonik findet. Farben aus dem KERN UX-Standard (Aktion dunkelblau
#2044aa, Erfolg türkis #007155 bzw. #16a884 auf Blau).

| Datei | Zweck |
|---|---|
| `kanonik-zeichen.svg` | Bildzeichen auf hellem Grund (Druck, Dokumente); in den Oberflächen setzt `design.js` es inline mit den Farben des Erscheinungsbilds ein (hell/dunkel) |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` (180 px), `kanonik-512.png` | Favicon und App-Symbol (Zeichen weiß auf Blau) |
| `og-bild-de.png`, `og-bild-en.png` | Vorschaubild 1200×630 für geteilte Links (Open Graph) |
