Introduction

How to read this demo:

  1. Choose a domain on the home page, for example the cinema ticket reservation.
  2. The guided tour shows in a few steps how specification, process and code relate.
  3. The gaps page lists every inconsistency found, with its kind, view and the requirements affected.
  4. Clicking a requirement opens the specification in the Document Structure Viewer at exactly that place.

The specifications were written for this demo; processes and code come from the open-source projects named.
