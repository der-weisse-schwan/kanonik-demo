K03Step 'Reservierung anfragen' missing in BPMN
The building block ci-anfrage-annehmen derived from the specification has no counterpart in the existing model camunda-cloud/src/main/resources/reserve-tickets.bpmn.
Follow-up gaps: K13
Speaks against it: 'ci-anfrage-annehmen' is the first step of the main process. The code starts the process in CinemaController.reserveSeat (POST /reservation); what happens before the process starts may be implemented there – then no step is missing in the BPMN, the specification is met in the code before the process (modelling decision). Before the start the method calls: UUID.randomUUID, zeebeClient.newCreateInstanceCommand, Map.of, request.getSeats, request.getName.
To check: Check whether the code performs these activities of the step: Reservierungsnummer vergeben; Eingang der Reservierungsanfrage bestätigen; Reservierungsanfrage ablehnen. If one of them is missing in the code as well, the gap remains (then rather to be closed in the code than in the BPMN).
